The five Commons description pages classify these simple logo designs as public-domain text logos; the brands remain their owners' trademarks. They are used here only to identify listed broadcasters.

Each download was inspected as XML with an SVG root, a valid viewBox and drawing elements, rather than accepted by file extension alone. Files range from 1.6–5.7 KB, totalling approximately 17 KB. Sanitization removed editor metadata, foreign elements, event handlers, nonlocal references and unsupported attributes/styles while preserving the original paths, transforms and brand colours. No scripts, external resources, embedded raster images or HTML remain. Preserve aspect ratios and do not recolour the marks. A small white rectangular backing keeps all five legible in both site themes.
